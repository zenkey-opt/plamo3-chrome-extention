PLaMo 3 Translate Local

PFN の翻訳特化 LLM「PLaMo 3 Translate」を、ブラウザの中（WebGPU）で動かして翻訳します。サーバーは不要で、訳文も原文も外部に送信しません。非公式拡張Built with PLaMo

保存領域の使用量
—
0 にすると解放しません。解放後の最初の翻訳は、読み込みに数秒かかります。

モデルは Hugging Face の公式リポジトリ（pfnet）から一度だけダウンロードし、この拡張機能専用の保存領域に置きます。翻訳はこの PC の GPU（WebGPU）で実行します。

モデルは Preferred Networks がPLaMo コミュニティライセンス契約で公開しているもので、ダウンロードして使うとこの契約が適用されます。事業での利用（組織の中での利用を含む）には事前の登録が必要です。
