# Chrome ウェブストアへの公開

Chrome ウェブストアに申請するときに入力する文と画像を、このフォルダに置いています。手順は 2026 年 11 月 12 日時点の Chrome ウェブストアのドキュメントに沿っています。ダッシュボードの画面の名前は英語の表記で書いています。

| ファイル | 使う場所 |
| --- | --- |
| `listing.md` | Store listing タブと Distribution タブ |
| `privacy.md` | Privacy タブと Test instructions タブ |
| `images/` | スクリーンショットとプロモーション タイル |
| `../extension/icons/icon128.png` | ストアのアイコン |
| `../PRIVACY.md` | プライバシーポリシー |
| `demo/article.html` | スクリーンショットを撮るページ |

## 1. デベロッパー アカウントを用意する

1. 公開に使う Google アカウントで 2 段階認証をオンにします。2 段階認証がないと、公開も更新もできません。Google は公開用に新しいメールアカウントを作ることを勧めています。
2. [デベロッパー ダッシュボード](https://chrome.google.com/webstore/devconsole)を開き、デベロッパー契約とポリシーに同意して、登録料 5 ドルを払います。登録料は 1 回だけです。
3. Account のページで次を入力します。
   - Publisher name：ストアの「提供元」に表示されます。
   - メールアドレス：確認のメールが届きます。確認したアドレスはストアの連絡先に表示されます。
   - 取引業者かどうか：EU の規則による申告です。取引業者と申告すると、確認された氏名や連絡先などがストアに表示されます。取引業者と申告しないと、EU の消費者とのあいだの契約に消費者の権利が適用されないことが表示されます。どちらにあたるかは開発者が判断します。

## 2. ZIP を作る

    python tools/pack-store.py

`dist/plamo3-translate-local-<バージョン>.zip` ができます。ストアは manifest に `key` があると受け付けないので、ZIP の manifest からは `key` を外しています。拡張 ID はストアが新しく割り当てます。

## 3. アップロードして各タブを入力する

1. ダッシュボードの「Add new item」で ZIP をアップロードします。
2. Store listing タブ：`listing.md` のとおりに入力し、アイコン、スクリーンショット、プロモーション タイルをアップロードします。
3. Privacy タブ：`privacy.md` のとおりに入力します。
4. Distribution タブ：`listing.md` の最後の表のとおりに選びます。
5. Test instructions タブ：入力しなくても公開できます。審査担当者向けの手順を `privacy.md` に用意しています。

## 4. 審査に出す

「Submit for review」を押します。確認画面で、審査が終わったらすぐ公開するかどうかを選べます。すぐ公開しない場合は、審査が終わってから 30 日以内に自分で公開します。30 日を過ぎると下書きに戻り、もう一度審査に出す必要があります。

審査にかかる日数は決まっていません。Google のドキュメントによると、2021 年の初めは 90% 以上が 3 日以内に終わりました。3 週間を超えたら、デベロッパー サポートに問い合わせます。

## 5. 公開したあと

- ストア版の拡張 ID は開発用の `bhkpaambekhpdikhkccbfdappiogpgnc` とは別になります。両方を同じブラウザに入れられますが、モデルの保存先も別になるので、ストア版ではモデルをもう一度ダウンロードします。
- 更新するときは、manifest の `version` を上げてから ZIP を作り直し、Package タブでアップロードして、審査に出します。
- README にストアのページへのリンクを足します。

## 画像を撮り直す

テスト用のブラウザを起動し、拡張機能のテスト用のコピーを同期してから撮ります。テスト用のプロファイルに 2B のモデルが入っている必要があります。

    bash tests/launch-test-browser.sh "$(cygpath -am .work/ext-test)"
    bash tests/sync-test-ext.sh
    node tools/store-shots.mjs

1 行目のブラウザは閉じるまで終わらないので、別のターミナルで動かします。アイコンとプロモーション タイルは `python tools/make-icons.py` で作り直します。
